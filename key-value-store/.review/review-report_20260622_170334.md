## 2. Spec ⇄ Test Alignment

The agent is dropped into `/app` containing the shipped `README.md` (full design doc +
API table), `TypeRegistry.cs`, `SnapshotModels.cs`, and the demo. These define the exact
contract. **However, `instruction.md` does not tell the agent to treat those files as the
behavioral spec**, so the source-as-spec carve-out only partially applies; behaviors
specified *only* in the shipped files (not the prompt) are marked `~` (inferable).

**Direction A — test assertions vs `instruction.md`:**
- `Set`/`Get`/`TryGet`/`TryGet<T>`/`Remove`/`ContainsKey`/`Clear`/`Snapshot`/`Load`/`Dispose`/indexer/`Count`/ctors — ✓ explicitly listed.
- `Get_missing_key_throws` (KeyNotFoundException) — ~ in shipped README API table, not in prompt.
- `Snapshot_throws_for_unregistered_value_type` (InvalidOperationException) / `Load_throws_for_unregistered_type` (InvalidDataException) — ~ derivable from agent-visible `TypeRegistry.cs`, not in prompt.
- `Null_values_round_trip` — ~ inferable from nullable fields in `SnapshotModels.cs`, not in prompt.
- `Concurrent_writes_are_thread_safe` — ~ stated in shipped README ("Thread-safe…ConcurrentDictionary") but **absent from `instruction.md`** — a whole tested dimension the prompt never mentions.

**Direction B — `instruction.md` requirements vs tests:** clean. Every listed API/constructor is exercised; `Dispose` covered via `using var`. No untested requirement.

## 9. Revised Instruction

> **AAI policy note:** A third-party model (this reviewer) may not author `instruction.md`
> content. Per the hackathon HARD RULE, only the participant (or Avocado, mechanically)
> may write it. So instead of paste-ready prose, here is a content-free checklist of what
> to add/fix; author the wording yourself, sourcing details from your own
> `book/README.md` and `book/src/KeyValueDb/KeyValueStore.cs`.

Spec Clarity is "Requires Some Guessing", so a revision is warranted. Author should:
1. **Fix the typo:** "KeyValudeStore" → "KeyValueStore" (2×, Construction section).
2. **State thread-safety:** add that concurrent reads/writes must be safe (the suite stress-tests 8 threads × 1000 writes).
3. **State the exception contract:** missing-key `Get` throws `KeyNotFoundException`; `Snapshot` throws (`InvalidOperationException`) for an unregistered key/value type; `Load` throws (`InvalidDataException`) for an unregistered type or an unsupported snapshot version; and clarify that type-registration is validated at snapshot/load time, not at `Set`.
4. **One-line alternative that fixes 2–3 at once:** explicitly tell the agent that the existing `README.md`, `TypeRegistry.cs`, and `SnapshotModels.cs` in the working directory are the authoritative behavioral specification and must be honored — this converts the `~` items to explicit spec without enumerating each.

No change to difficulty or reward signal is implied; these are clarity fixes only.
