### Succinct (~10 lines)
```
Build a CLI tool named copy_data.py that copies a file locally and over the network.

local SRC DST [--chunk-size N]                         copy on the local filesystem
send HOST PORT SRC [--codec NAME] [--chunk-size N]     compress and send to a receiver
recv HOST PORT DST [--chunk-size N]                    receive, decompress, and write

Local copy: byte-exact; stream in chunks (do not load the whole file into memory);
create the destination directory if missing; overwrite an existing destination.
Network transfer: a recv process binds HOST:PORT and a send process connects;
the payload is compressed in transit (zlib) and reconstructed byte-for-byte;
works on loopback. A failed or interrupted transfer must leave no partial or
corrupt file at DST. All errors exit non-zero with a message on stderr.
```

### Regular
```
# Database copy tool

Build a command-line tool named `copy_data.py` that copies a file between
database copies, both locally and over the network.

## Commands
- `python copy_data.py local SRC DST [--chunk-size N]`
- `python copy_data.py send HOST PORT SRC [--codec NAME] [--chunk-size N]`
- `python copy_data.py recv HOST PORT DST [--chunk-size N]`

## Local copy
- Copy SRC to DST byte-for-byte.
- Stream in fixed-size chunks so memory use stays bounded regardless of file size.
- Create the destination directory if it does not exist; overwrite DST if present.

## Network transfer
- `recv` binds HOST:PORT and waits; `send` connects and transfers SRC to it.
- The payload is compressed in transit; `zlib` is the default codec and must be a
  valid value for `--codec`.
- The received file must equal the source byte-for-byte.
- The transfer must work over loopback (127.0.0.1).
- A failed or interrupted transfer (dropped connection, short/malformed stream)
  must leave no partial or corrupt file at DST.

## General
- On success, exit 0.
- On any error, exit non-zero and print a message to stderr.
```
