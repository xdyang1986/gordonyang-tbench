# Large-Scale Observability for Ride-Hailing — Multi-Turn Task (Hardened)

This is a multi-turn terminal-bench task with 2 steps, now significantly hardened. You are building an observability library in Go for a ride-hailing platform handling 10k+ req/sec.

## Overall Goal
Implement package `observability` in module `ride-observability` that provides:
- Distributed tracing with `TraceContext` propagation (TraceID 32 hex, SpanID 16 hex) via single-header `x-ride-trace`, with strict Flags, ParentID consistency, nil handling, defensive copies, duplicate-key rules
- Metrics (Counter, Gauge, Histogram) with thread-safety, defensive copies for WithLabels/WithBuckets, label/truncation-before-key reuse, Gauge NaN/Inf ignore, histogram bucket dedup+sort, deep copy Collect including Buckets, and cardinality limiting in step2
- Structured JSON logging correlated with tracing, atomic per-line writes, shared mutex across With chain, immutable With, level case-insensitive, nil output fallback
